# Student documentation

This folder is the authoritative assignment handout. If verbal guidance
conflicts with these documents, ask the teaching team to clarify and record the
decision.

Recommended reading order:

1. `getting-started.md`
2. `brief.md`
3. `plain-language-guide.md`
4. `quantum-data-primer.md`
5. `data-sources.md`
6. [Parquet in this assignment](plain-language-guide.md#parquet-in-this-assignment)
7. `silver-tables.md`
8. `required-ml-tables.md`
9. `part-2-ai-ml.md`
10. `rubric.md`
11. `submission-checklist.md`


Use `faq.md` while working. It covers both conceptual questions and common
platform problems without prescribing the reference solution. The instructions
prefer the terminology used in the course schedule: discovery, cleaning,
integration, relational databases, data lakes, and databases for ML.

The assignment lasts four weeks. Part I is intentionally larger than Part II,
and numerical model performance is not part of the grade.
